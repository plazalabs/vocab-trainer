### 1.2 기존 디자인(v5, `81f76b1`)에서 관찰된 정량 문제점
1. **단일 보라색 과점 및 토큰 불일치**: `css/style.css` (3,978줄 / 95,127바이트)에 `--brand-primary`, `--xp-primary`, `--sky-primary`, `--info-primary`, 진행 링(`.v5-ring-fg`), 초대형 복습 숫자(`.v5-bignum-value`), 히어로 CTA(`.v5-cta`), 퀴즈 진행 바(`.progress-fill`)가 모두 `#6D36D5`로 덮어쓰여 있으면서도 `--brand-soft: #EFF6FF`, `--brand-border: #BFDBFE`, `theme-color: #2563EB` 등 구 v2 파랑 토큰이 혼재되어 있음.
2. **모바일(390px) 핵심 동기부여 요소 누락**: `css/style.css` 3695행 `@media (max-width: 480px)`에서 `.streak-pill { display: none; }`으로 스트릭 배지가 모바일 헤더에서 숨겨짐.
3. **홈 화면 학습 모드 2종 미노출**: 앱의 학습 모드는 총 5종(기본 3종 + 기출 다의어 2종)이나, 홈 화면 `.quiz-mode-grid`에는 기본 3종(`뜻 맞히기`, `예문 빈칸`, `카드 뒤집기`)만 배치되어 기출 2종(`기출 예문 빈칸`, `문맥 속 뜻`)으로의 즉시 진입이 불가함.
4. **과밀한 카드 구조와 곡률·그림자 난립**: `border-radius` 선언 **107회**(8/12/16/20/24/999px 6단계 혼재), `box-shadow` 선언 **57회**(다층 블러 + 보라 글로우 `rgba(109, 54, 213, 0.35)`). `.status-card`는 고정 높이 `192px` + `overflow: hidden` 상태에서 초대형 숫자(`44px`)·3열 통계·레벨 바·주간 도트·SRS 바·목표 칩·시뮬레이션 바가 한 컨테이너에 중첩됨.
5. **퀴즈 표제어 위계 부족**: 퀴즈 핵심 대상 단어(`.quiz-target-word`)가 `28px`에 머물러 상단 설정 바(`88px`) 및 하단 고정 피드백 배너(`max-height: 54vh`) 대비 시선 집중도가 낮음.

## 3. Concept A — 게임형 (Playful Tactile Arcade)

- **시안 파일**: [`design-mockups/concept-a.html`](./concept-a.html)
- **참고한 실존 앱**: **Duolingo** (3D 눌리는 하단 립 버튼·상단 캔디 프로그레스 바·하단 전면 정답 피드백), **말해보카** (캐릭터 동반 일일 목표·즉각적 격려 카피), **Drops** (학습 모드별 선명한 아이콘 색면)

### 3.1 디자인 의도
등하교길·쉬는 시간에 3분 단위로 부담 없이 1세션을 시작하도록 **물리적 손맛(Tactile 3D Press)**과 **즉각적 보상 감각**을 극대화했다. 기존 v5가 말해보카 문법을 차용하면서도 화면 전체를 단일 보라색으로 칠해 단조로워진 문제를 해결하기 위해, **색상별 의미를 엄격히 분리**(행동/성공=에메랄드, 히어로 활기=선샤인 옐로우, 스트릭/콤보=텐저린 오렌지, XP/음성=스카이 블루, 수능 기출=딥 틸)했다.

### 3.3 글꼴 체계
- **한글 UI**: `"Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", -apple-system, BlinkMacSystemFont, sans-serif`
- **영문·숫자**: `"SF Pro Rounded", "Hiragino Maru Gothic ProN", ui-rounded, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif` (`tabular-nums`)
- **스케일**: 퀴즈 표제어 `36px / 900` · 히어로 헤드라인 `19px / 900` · 정답 피드백 제목 `17px / 900` · CTA `16px / 900` · 선택지 `15px / 800` · 메타 필 `11~12px / 800`

### 3.4 모서리·그림자 규칙
- **모서리**: 카드 `20px`, 버튼·선택지 `16px`, 칩 `12px`, 배지·프로그레스 바 `999px` (4단계 고정).
- **그림자**: **블러(blur-radius) `0px` 전면 폐기**. 모든 입체감은 `2px solid` 테두리 + 하단 단색 립 `box-shadow: 0 4px 0 <lip-color>`(CTA/히어로) / `0 3px 0`(카드/선택지) / `0 2px 0`(보조 버튼)으로 표현. `:active` 시 `translateY(2~3px)` + `0 1px 0`으로 실제 눌리는 감각 제공.

### 3.5 이전 디자인(v5) 대비 정량 변화
- 보라색 사용 `50회 → 0회`, 그라데이션 `2회 → 0회`.
- 블러 기반 `box-shadow` `57회 → 0회` (하드 3D 립 21회로 대체).
- 퀴즈 표제어 `28px → 36px (+28.6%)`, 진행 링 두께 `7px → 9px (+28.6%)`.
- 홈 화면에서 기본 3종 + 기출 2종 = **5종 전체**를 1스크린 내 즉시 실행 가능하게 재구성.

## 4. Concept B — 도구형 미니멀 (Calm Swiss Utility)

- **시안 파일**: [`design-mockups/concept-b.html`](./concept-b.html)
- **참고한 실존 앱**: **Things 3** (넓은 여백·얇은 진행 링·절제된 단일 액센트), **Linear (Light Mode)** (1px 헤어라인 경계·모노스페이스 메타·그림자 제거), **Notion** (정보 밀도 제어 리스트), **모던 Anki 클라이언트** (방해 요소 없는 암기 집중 화면)

### 4.1 디자인 의도
수능·내신 대비로 하루 30~60분 이상 단어를 반복 암기하는 학생에게 **시각적 피로가 가장 적은 차분한 도구**를 제안한다. 캐릭터·이모지·컬러 칩·다중 배지를 모두 제거하고, **순백 여백(`22px` 좌우 패딩, `28px` 섹션 간격)**, **1px 헤어라인 정렬**, 그리고 **유채색 단 1종(`#0F766E` 딥 틸)**만으로 오늘의 목표→퀴즈→정답 확인 흐름을 완성한다.

### 4.2 색상 팔레트 (Hex) — 유채색 1개 엄격 제한
| 역할 | 토큰 / 용도 | Hex | 비고 |
| :--- | :--- | :--- | :--- |
| 배경 / 미세 서피스 | `--bg` / `--surface-subtle` | `#FFFFFF` / `#F7F7F8` | 순수 무채색 |
| 경계선 (헤어라인) | `--hairline` / `--hairline-strong` | `#E4E4E7` / `#D4D4D8` | 모든 구획을 1px 선으로 처리 |
| 텍스트 4단계 | `--ink-1` / `--ink-2` / `--ink-3` / `--ink-4` | `#18181B` / `#52525B` / `#71717A` / `#A1A1AA` | 주 텍스트 대비 17.72:1 (AAA) |
| **유일한 유채색 (Deep Teal)** | `--accent` / `--accent-hover` | `#0F766E` / `#115E59` | CTA·진행 링·2px 진행 선·정답 상태 통합 (대비 5.47:1) |
| 유일 유채색 틴트 | `--accent-wash` / `--accent-line` / `--accent-ink` | `#F0FDFA` / `#99F6E4` / `#134E4A` | 정답 선택지·피드백 시트 (대비 9.09:1) |

> **1색 원칙 검증**: 스트릭(`7일 연속`), XP(`Lv.4 · 340 XP`), 오답 개수(`3`), 품사/학년 태그(`v.`, `고1`) 모두 무채색 타이포/헤어라인으로 처리해 화면 전체의 유채색 Hue를 **1개(Teal, ~175°)**로 엄격히 제한했다.

### 4.3 글꼴 체계
- **본문·제목**: `-apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", "Segoe UI", sans-serif`
- **수치·진도·메타**: `ui-monospace, "SF Mono", Menlo, Consolas, monospace` (`tabular-nums`)
- **스케일**: 퀴즈 표제어 `34px / 600` · 목표 수치 `24px / 600` · 앱 제목 `15px / 600` · 선택지 `14.5px / 500` · 리스트 설명 `12px / 400` · 모노 메타 `11~11.5px / 500` (`700~900` 과다 볼드 배제)

### 4.4 모서리·그림자 규칙
- **모서리**: 리스트 컨테이너 `10px`, 버튼·선택지 `8px`, 태그·세그먼트 `6px` (3단계 절제, `999px` 알약 남발 제거).
- **그림자**: **`box-shadow` 0회** (완전 플랫). 위계는 오직 여백, `1px` 헤어라인, 폰트 크기/명도 대비로만 표현.

### 4.5 이전 디자인(v5) 대비 정량 변화
- 유채색 종류 `4색(보라·파랑·주황·초록·빨강 5계열 혼재) → 1색(#0F766E)`.
- `box-shadow` 선언 `57회 → 0회 (-100%)`, `border-radius` 선언 `107회 → 11회 (-89.7%)`.
- 퀴즈 상단 진행 바 높이 `6px → 2px (-66.7%)`, 진행 링 굵기 `7px → 3.5px (-50%)`.
- 좌우 기본 여백 `16px → 22px (+37.5%)`, 퀴즈 표제어 `28px → 34px (+21.4%)`.

## 5. Concept C — 에디토리얼·카드형 (Literary Print & Typographic Card)

- **시안 파일**: [`design-mockups/concept-c.html`](./concept-c.html)
- **참고한 실존 앱**: **Vocabulary.com** (사전 표제어 중심 어휘 경험), **Readwise Reader** (따뜻한 종이 배경·독서 중심 타이포), **NYT Games** (신문 마스트헤드·날카로운 룰과 세리프 대비), **Kinfolk / Monocle 디지털 에디션** (목차 넘버링 `01~05`·대문자 소제목 위계)

### 5.1 디자인 의도
영단어를 '시험 대비 체크박스 항목'이 아니라 **한 장의 종이 엽서이자 사전의 표제어(Headword)**로 대우한다. 홈 화면 상단부터 오늘 복습할 대표 표제어(`abandon`)를 `36px` 세리프로 전면 배치하고, 퀴즈 화면에서는 **`44px` 대형 세리프 표제어**를 적층 인덱스 카드 위에 올려 **단어 자체가 화면의 주인공**이 되도록 설계했다.

### 5.2 색상 팔레트 (Hex)
| 역할 | 토큰 / 용도 | Hex | 비고 |
| :--- | :--- | :--- | :--- |
| 지면 배경 (Archival Paper) | `--paper` | `#F5EFE4` | 따뜻한 인쇄 종이 톤 (눈부심 완화) |
| 인덱스 카드 표면 | `--card` / `--card-tint` | `#FFFDF8` / `#FBF7EE` | 코튼 오프화이트 |
| 잉크 (주/보조/캡션) | `--ink` / `--ink-2` / `--ink-3` | `#1C1917` / `#4A453F` / `#7C746A` | 본문 대비 15.28~17.20:1 (AAA) |
| 지면 룰 (구분선) | `--rule-light` / `--rule-mid` | `#DDD4C4` / `#C4B8A3` | 헤더·카드는 `1.5~2px solid #1C1917` |
| 에디토리얼 인장 (Vermilion) | `--vermilion` / `--vermilion-soft` | `#B93815` / `#FDF1EC` | 스트릭·진행 링·목차 번호 `01~05`·XP 스탬프 (대비 5.68:1) |
| 정답 주석 (Bookbinding Sage) | `--sage` / `--sage-soft` / `--sage-ink` | `#2D6A4F` / `#EDF5F0` / `#1D4B37` | 정답 선택지·인용 예문 블록 (대비 8.95:1) |

### 5.3 글꼴 체계
- **영문 표제어·인용 예문·이슈 번호**: `Georgia, "Iowan Old Style", "Palatino Linotype", "Times New Roman", serif`
- **한글 대제목·섹션명**: `"AppleMyungjo", "Batang", "Noto Serif KR", Georgia, serif`
- **UI 라벨·메타·선택지**: `-apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", sans-serif` (키커 `10px / 700 / letter-spacing: 0.08~0.10em / uppercase`)
- **스케일**: 퀴즈 표제어 **`44px / 400`** · 홈 스포트라이트 표제어 `36px / 400` · 마스트헤드 제목 `21px / 700` · 인용 예문 `14.5px` · 선택지 `14.5px / 500`

### 5.4 모서리·그림자 규칙
- **모서리**: 인쇄 카드 물성을 살린 날카로운 곡률 — 카드 `4px`, 버튼·선택지 `3px`, 스탬프 태그 `2px` (3단계).
- **그림자**: 블러 `0px` — 단단한 종이 오프셋(`box-shadow: 3px 3px 0 #DDD4C4`) 4회만 절제 사용. 퀴즈 표제어 카드 하단에는 `::after` 의사 요소로 다음 인덱스 카드가 살짝 비치는 **적층 카드(Stacked Card)** 구조 적용.

### 5.5 이전 디자인(v5) 대비 정량 변화
- 퀴즈 표제어 크기 `28px → 44px (+57.1%)` — 3종 컨셉 중 단어 주목도 최대.
- 카드 모서리 반경 `16~20px → 4px (-75~80%)` — 둥근 앱 템플릿에서 탈피한 인쇄물 조형.
- 보라색 `50회 → 0회`, 그라데이션 `2회 → 0회`, `box-shadow` `57회 → 4회 (-93.0%)`.
- 예문 피드백을 단순 메타 텍스트에서 **세리프 인용구(`<blockquote>`) + 밑줄 강조** 구조로 격상.

## 6. 임의 결정(유보) 항목

시안 제작 범위상 저장소 명세(`index.html`, `data/words.json`)에 고정값이 없거나 구현 단계에서 확정이 필요한 아래 항목은 **유보**로 기록한다.

1. **시안용 샘플 학습 상태값**: 실제 앱 초기 상태(`0일 연속`, `0%`, `Lv.1 · 0 XP`) 대신 활성 학습자의 화면 밀도를 검증하기 위해 `7일 연속`, `Lv.4 · 340 XP`, `오늘 목표 14/20 (70%)`, `오늘 복습 6개`, `퀴즈 4/10 (정답 3개)`, `오답노트 3개`, `다음 복습 3일 뒤 · 11월 22일`, `이번 주 월~토 완료`를 임시 대입함.
2. **4지선다 오답 보기 선정**: 정답 `abandon` (`포기하다, 버리다`, `data/words.json` id:1)의 오답 3개는 같은 파일의 동사 항목(`accommodate`, `adapt`, `acknowledge`) 뜻을 임의 조합함.
3. **Concept A 마스코트 캐릭터 시안**: 기존 `index.html`의 base64 WebP 마스코트를 복사하지 않고, 인라인 SVG로 새싹 모티프 학습 캐릭터(홈·피드백 2표정)를 임시 제작함. 실제 브랜드 캐릭터 확정 여부는 유보.
4. **Concept B의 정답·오답 1색 확장 규칙**: 시안은 정답 상태만 포함하므로 단일 액센트(`#0F766E`)로 완벽히 통일되었으나, 실제 구현 시 **오답 상태**를 무채색+아이콘/텍스트로 유지할지, 최소한의 경고색 1종을 예외 허용할지는 디자인 확정 단계로 유보.
5. **Concept C 한글 명조 시스템 폰트 편차**: 외부 리소스 금지 제약으로 `"AppleMyungjo", "Batang", "Noto Serif KR"` 폴백 스택을 사용했으나, OS별(iOS/macOS/Android/Windows/Linux) 설치된 명조 폰트 유무에 따라 렌더링 편차가 발생함. 실구현 시 경량 서브셋 웹폰트 도입 여부는 유보.
6. **미포함 화면 및 다크 테마**: 요청 범위에 따라 홈 화면·퀴즈 화면(라이트 기본)만 정적 시안으로 제작했으며, 단어장·오답노트·기출 다의어 카드·세션 결과·다크 모드 변형·실제 JS 상호작용은 본 시안 범위 밖으로 유보함.
